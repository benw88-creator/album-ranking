## Grades

- **A — Already authorised.** A document we hold or can cite covers the current use.
- **B — Authorised with small changes.** Published terms allow it once we add attribution, links or badges, or adjust the use.
- **C — Permission obtainable.** A rightsholder or provider would have to grant it.
- **D — Not currently authorised.** No permission has been established.

C and D are never presented to Apple as existing permission.

## The short version

1. **Strongest evidence we can submit now:**
   - YouTube's own terms for Community Choice (A, with one sentence added to VINALL's terms).
   - Apple's own Search API terms for artwork and previews on promotional screens (B).
   - CC0 for the MusicBrainz data in Music Passport (A).
   - VINALL's own data for ratings, social features and the economy (A).
   - The new screenshots (A).
2. **Deezer is D, and accepting Deezer's published terms would not change that:**
   - They "grant no right upon … the Content".
   - They cover only "Personal Applications" for "strictly private use within a family scope".
   - They forbid association "with any trademark, brand name, or logo".
   - Only a signed Deezer agreement (C) keeps Deezer as it is.
3. **The original screenshots are D.** Apple's promotional licence excludes promoting "any other goods or services", so it cannot cover our app's own marketing. Keeping real covers there needs written permission per cover (C).
4. **Recommendation:** make targeted changes and submit the evidence, while asking Deezer for an agreement in parallel. Details are in `APP_REVIEW_RESPONSE.md` and the closing summary.
